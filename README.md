# Hosroom Tools

Programa de escritorio de Hosroom para el equipo de revenue y contenido, en Windows y Mac.

## Herramientas

- **Estructuras** de tarifas de los hoteles.
- **Panoramas**: tarifas de la competencia por fecha, temporadas, costo operativo y llenado desde Booking.
- **Informe de Ventas** e **Informe de Ocupación**.
- **Base de datos Hoteles**.
- **Banners** y **Fotos OTA**.
- **Chat** interno del equipo, con grupos, imágenes, stickers y GIF.

## Instalar en Windows

1. Entra a [la última versión](https://github.com/Zhadowlone/hosroom-tools/releases/latest) y descarga `Instalar-Hosroom-Tools-X.Y.Z.exe`.
2. Ábrelo. Si Windows muestra «Windows protegió tu PC», elige «Más información» › «Ejecutar de todas formas».
3. Entra con tu usuario y tu PIN.

## Instalar en Mac

1. Entra a [la última versión](https://github.com/Zhadowlone/hosroom-tools/releases/latest) y descarga `Hosroom-Tools-X.Y.Z-mac.dmg` (sirve para Mac con chip Apple M e Intel).
2. Abre el `.dmg` y arrastra **Hosroom Tools** a **Aplicaciones**. Ábrelo siempre desde Aplicaciones para que se actualice solo.
3. La primera vez, el Mac dirá que es de un desarrollador no identificado: clic derecho sobre la app › **Abrir**. Si no te deja, ve a Configuración › Privacidad y seguridad › «Abrir de todas formas». Solo se hace una vez.
4. Entra con tu usuario y tu PIN.

## Actualizaciones

En Windows y en Mac el programa revisa solo si hay una versión nueva, la descarga, verifica su huella y se actualiza. Antes avisa para que guardes tu trabajo.

Este repositorio solo publica los instaladores. El código no está aquí.
